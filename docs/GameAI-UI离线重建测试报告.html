2. 可复现命令

UnityCLI --project <当前Unity工程> --format json prefab restore \
  --json <ui-template/1快照.json> \
  --prefab Assets/GameAI/Tests/UiLibrary/UIRecallMemoryItem.prefab --dry-run

# 首次写入：移除 --dry-run；已有资产必须显式 --replace。

restore 独立于 prefab create，不把模板根节点强制全屏拉伸。在临时预览场景创建，保存为独立资产，不更改或保存用户当前场景。只支持明确注册的标准UGUI组件；未知类型、缺失属性或歧义引用会拒绝。
