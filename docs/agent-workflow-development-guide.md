# 多角色流程开发指导

Design：先调研，再集中澄清，形成 app/desgin 下独立 HTML。

人工：确认完整版本与原始文档；当前正式审批服务尚未接入。

PM：原始文档保存并核验成功后，按交付标准拆为主任务下的美术、程序、QA 子任务，保留任务级依赖与交付顺序。

Orchestrator：在 GameCLIServer 中核对 PostgreSQL 状态、审批和依赖，持久化租约并选择空闲节点。当前节点接单和自动派工尚未接入。

Art / Development / QA：严格在任务范围内交付真实产物、版本和测试证据，结果由服务写入任务记录和评论；美术抽检和最终人工验收保留。

现有可执行入口只有 CLI 插件管理、Unity ping 和 PM 只读分析；Track 支持数据库读取、HTML 查看与本机 Agent 配置。旧的本地多角色调度命令已经移除，不能按历史操作说明调用。

具体规范见包内 game-cli 各单一职责 SKILL，以及 GameAI协作平台技术开发纲要.html。
