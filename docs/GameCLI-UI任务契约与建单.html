职责与数据

GameCLI task 插件负责输入文件和进程传输；GameAI.Server负责固定Schema、PostgreSQL权威存储、事务建单与权限检查。CLI不新增本地调度器。数据库保存不可更新的生产契约与任务执行输入。每个窗口固定生成白模、Art、装配三项，角色、依赖、编号及交付目录由代码决定。

服务端迁移028建立 ui_production_contracts、ui_task_plan_requests、ui_task_contracts。Hash使用递归排序对象键的规范JSON；数组顺序保留。以读取/校验后的Schema对象计算哈希，不能直接拿格式化文件的SHA代替。

命令

GameCLI task contract validate --input contract.json
GameCLI task plan validate --input plan.json --contract contract.json
GameCLI task contract register --input contract.json --user <human UUID>
GameCLI task plan validate --input plan.json --user <human UUID>
GameCLI task plan submit --input plan.json --user <human UUID>

在仓库目录中自动定位GameAI.Server；其他位置使用 --server <目录>。离线validate不连接数据库，不能证明审批有效。在线validate与submit读取数据库重新核对权限、最新需求审批、契约哈希及主任务。注册与提交使用服务器本机配置的数据库身份，这是受信任宿主上的维护入口；--user是审计主体，不是远程身份认证令牌。不得把此本机适配器直接开放为匿名远程接口。

示例位于 game-cli/src/GameAI.Server/examples/ui-task-plan/；ID均为示例，不对应生产记录。可直接离线校验。机器可读Schema位于 schemas/ui-tasks/，由 ui-production-contract.js 的Zod定义导出。

审批与原子性

正式契约必须在人工审批之前嵌入需求HTML，且位于唯一的 script#ui-production-contract[type="application/json"] 中。登记只接受与已批准HTML完全一致的契约。审批过期、新需求版本出现、文档哈希不符均拒绝。

<script id="ui-production-contract" type="application/json">
{ ...完整生产契约... }
</script>

plan.parentTaskId必须指向相同需求已发布计划中的PM根任务。已有相同窗口任务时拒绝覆盖。完整三阶段单事务创建，不自动开启权限或流程。已有任务授权入口仍控制派发。

requestId在项目内幂等：相同内容返回原任务，不同内容拒绝。进程超时后的提交结果可能已落库，必须用相同requestId与内容重试。事务回滚不会留下部分任务，数据库编号序列可能产生空号。

派发时按taskId读取被冻结的执行输入，验证哈希并保存为 game-cli/temp/task-jobs/<executionId>/production-input.json；所有阶段获得相同窗口契约，以及各自阶段、交付目录和依赖任务ID。

校验范围

检查严格字段、完整阶段、版本哈希、窗口与路径唯一、单根和父子环、节点与组件ID、槽位绑定、图片尺寸/PPU/切片、复用来源、动画特效目标和槽位引用。禁止组件内夹带旧assetPath/guid。无动画/特效也必须显式给出空数组。验收配置与风格引用必须具备版本；视觉规范内容仍需按相应专业工具验证。

当前边界

此次实现是契约登记、固定建单及执行输入传递。没有把旧的PM文本拆分自动迁移到新入口，也没有重建当前登录任务或修改审批。当前旧文档不含此契约，不能直接注册为新标准。需更新文档并人工审批后使用。

production-input.json是跨角色任务输入，不是直接可传给UnityCLI prefab restore的ui-template/1或ui-assembly/2。资源交付版本解析、最终装配包编译及Unity dry-run仍需后续接入；不能将此处schema校验称为Unity装配验证。动画/特效specification保留结构化专业参数，本入口验证其引用，具体参数仍由Unity工具验证。

测试覆盖离线校验、真实PostgreSQL审批拒绝、事务回滚、重复提交、固定依赖和执行输入不可修改。数据库测试使用独立测试项目并整事务回滚，不覆盖现有任务。
