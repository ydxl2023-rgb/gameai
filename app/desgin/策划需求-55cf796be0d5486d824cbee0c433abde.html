1 设计目标

提供简洁的移动端测试登录入口，用本地安装 ID 串联选服、模拟登录、首次建号及成功页面，便于检查完整交互和各服务器数据隔离。

  • 本期完成模拟登录测试闭环，不连接真实登录服务。
  • 应用安装 ID 是本地生成并保存的标识，不是永久硬件 ID，也不是安全认证凭据。
  • 手机号、用户名、密码、注册输入、真实认证、账号找回、跨设备继承及奖励系统均不在本期。
  • 仅设计移动端触屏操作；设计画布为 1920×1080 横屏，运行时适配设备实际安全区。

2 功能综述

编号主题确定规则
R01安装标识首次安装使用时生成并持久化安装 ID；重复启动读取同一个 ID。标识数据丢失后生成新 ID，并视为新账号，不自动关联旧账号。
R02模拟账号以安装 ID 与服务器 ID 的组合定位模拟账号。首次在对应服务器成功登录时自动建号；后续复用。不同服务器的数据独立。
R03选服从本地配置按行顺序读取服务器列表。上次选择仍存在且可用时优先恢复，否则选择首个可用服。不可用服保留展示但禁止选择。
R04无可用服没有可用服务器时显示“暂无可用服务器”，登录按钮禁用。列表为空时选服控件同时禁用；列表非空但全不可用时允许展开查看，全部条目禁选。
R05版本展示左上角完整展示测试 ICON 与 32 位字母数字版本号。版本号仅展示，不参与登录校验、版本匹配或登录阻断。
R06请求状态模拟登录处理中同时禁用选服及登录按钮，关闭已展开的下拉列表；成功后进入占位主界面。
R07失败及超时明确失败或模拟超时均使用屏幕中部出现、向上飘动后消失的原因提示条；恢复符合当前可用条件的选服与登录操作，不自动重试。
R08表现范围简洁测试风格，静态背景；窗口显示及切换不制作开关动画，按钮不制作音效。失败提示条的上飘及消失是本期唯一必需的动态反馈。

本期所有登录结果来自本地模拟，不存在真实远端发号或远端提交结果未知的场景。模拟超时结束当前尝试，旧尝试的迟到结果不得改变当前页面、账号或选服状态。玩家可恢复操作后手动再次登录；不增加重试按钮、网络异常窗口或自动查询网络服务。

模拟建号与成功结果作为同一有效尝试的完成步骤；失败或已超时尝试不提交新账号。相同安装 ID 与服务器 ID 的重复成功登录不得重复建号。配置、标识或模拟数据读取／保存失败时不伪装成功。

3 界面与交互

以下线框是低保真制作依据，包含 Design 在授权范围内确定的布局。占位颜色与图形不表示已制作正式资源。手机外框、左侧刘海、手势条、安全区虚线、编号及引线均为文档辅助标记。

所有窗口共用 1920×1080 设计画布。坐标原点为父节点左上角，x 向右、y 向下；表中尺寸单位为设计像素。根节点铺满屏幕，关键内容约束在实际安全区内；示意安全区为 (130,65,1660,905)，不将示意边距硬编码为设备安全区。

组件树的 S 数字表示同父节点从底到顶的 Sibling 顺序，不代表独立 Canvas 或 Canvas.sortingOrder。每个节点的相对布局、类型和输入属性见对应表；共用属性见 3.6。所有图片使用静态 Image.Type.Simple；本期没有九宫格图片。

3.7.2 校验、错误处理与生效

  • 服务器列表加载前校验字段存在、主键唯一、名称长度及布尔类型；字段错误时不跳过坏行拼装可登录列表，按配置读取失败处理，禁用登录并显示原因提示。
  • 合法的零条服务器列表不视为解析失败，按“暂无可用服务器”处理；非空但全部不可用时遵循 R04。
  • 版本号的 32 位字母数字要求是配置制作及人工验收标准。登录逻辑不得检查、比较该字符串或据此放行／拒绝登录；即使测试注入异常版本文本，也不得影响模拟登录结果。
  • 展示信息缺失时不伪造版本，L03 显示“版本信息缺失”；服务器列表仍独立决定能否登录。正常交付配置必须提供完整规定字符串。
  • 本地配置在应用启动时加载，本次运行固定使用该份配置；替换配置在下次启动生效，不增加运行中刷新入口或热更行为。
  • 更新配置后，按 ServerId 恢复上次选择；不存在或不可用时回退到首个可用服。修改 ServerName 不改变账号身份；改变 ServerId 视为不同服务器数据域。
  • 不清除其他服务器已有模拟数据；配置中移除的服务器本期不可进入。恢复相同 ServerId 时仍使用对应原数据。
  • 不增加账号进度、安装 ID、上次选择、模拟登录结果、超时数值、认证地址或真实接口字段到工作簿。模拟成功、失败和超时由测试夹具控制，不新增玩家设置界面。

3.7.3 本地运行数据边界

数据性质生命周期与约束
安装 ID本地运行数据，非配置首次使用生成并成功保存后复用；可采用随机生成的 Guid，以字符串持久化。不得读取硬件标识来替代已批准方案。
上次服务器 ID本地运行数据，非配置选定可用服时记录；重启复用，失效时回退。保存失败不宣称记忆成功，提示本地数据保存失败。
模拟账号与服务器数据本地运行数据，非配置按安装 ID 与 ServerId 隔离并持久化；首次成功建号、后续复用。无跨设备继承或真实服务端同步。
当前尝试标记与状态运行中临时状态，非配置区分有效尝试及过期回调；进程退出后不自动恢复请求、不自动登录。

3.8 操作交付标准与程序需求

以下按操作链定义程序交付结果，未创建专业任务。每项测试均为计划，完整用例见附录 A。

OP01 启动与本地状态恢复

  • 前置条件：启动应用；本地配置与运行数据可能为首次、已有或丢失状态。
  • 操作处理：显示登录窗口，读取本地配置、安装 ID 及上次选服；初始化尚未完成时禁用登录，避免使用不完整状态。
  • 成功结果：缺少安装 ID 时生成并保存；已有 ID 时复用。恢复有效的上次服务器，否则选择首个可用服；显示 ICON 和完整版本号。
  • 失败反馈：配置或本地存储异常显示 F00 原因提示。缺少有效安装 ID、有效服务器配置或可用服时不允许登录；显示数据不可被误认为已经保存。
  • 异常恢复：重新启动时重新读取本地状态；不自动发起登录。标识数据丢失按新账号处理，不尝试找回旧账号。
  • 测试用例：T01、T02、T03、T04、T05、T12、T13、T17。

OP02 展开、浏览、选择及关闭服务器列表

  • 前置条件：初始化完成且当前不在登录中；至少存在一条合法配置。
  • 操作处理：点击 B01 显示 D00；条目按配置排列。触屏纵向拖动 D03 只浏览列表，拖动结束不触发选服。内容未溢出时不滚动。
  • 成功结果：点击可用 D07[n] 更新 B01-T、记录上次服务器并关闭 D00；点击外部 D01 只关闭 D00、保持原选择；不播放开关动画。
  • 失败反馈：不可用项禁选，原选择保持。记忆写入失败用 F00 显示原因，不谎称已保存；本次内存选择可继续使用，重启以实际持久化结果为准。
  • 异常恢复：展开、滑动和关闭均为本地交互，无网络调用；下次启动重新校验上次服务器是否存在且可用。登录中对 B01 的点击不进入本操作。
  • 测试用例：T03、T04、T05、T06、T07、T13。

OP03 模拟登录与首次建号

  • 前置条件：安装 ID 有效并已保存，已选择可用服务器，当前没有正在处理的尝试。
  • 操作处理：点击 B02 固定本次安装 ID 和服务器 ID，发起一次本地模拟尝试；收起 D00，B01 和 B02 禁用，B02-T 显示“登录中…”。不得启动真实登录 API。
  • 成功结果：当前有效尝试成功时，以安装 ID 与服务器 ID 查找或创建模拟账号；持久化成功后显示 M00，并隐藏登录窗口与提示。重复登录同服复用账号，不同服独立。
  • 失败反馈：模拟失败或本地数据提交失败时不进入 M00；显示准确的 F00 原因提示，恢复当前可用条件下的 B01、B02 和“登录”文案。
  • 异常恢复：模拟超时结束本次尝试，显示“模拟登录超时，请再次登录”，恢复操作，不自动重试。过期结果和旧页面回调不得建号、跳转或覆盖新选择；进程中断后下次启动重新进入登录窗口。
  • 测试用例：T08、T09、T10、T11、T14、T15、T16。

OP04 原因提示的显示与恢复

  • 前置条件：启动、本地保存或模拟登录产生需要告知玩家的失败／超时原因。
  • 操作处理：F01 与 F02 从屏幕中间显示，播放 AN01 上飘及消失表现；没有确认、关闭或重试按钮，不接收射线。
  • 成功结果：提示播放结束后隐藏；底层操作资格由真实状态决定。模拟失败和超时恢复正常操作，不等待提示结束。
  • 失败反馈：原因使用对应中文类别，不能把超时表现成登录成功，也不能显示虚构的远端认证错误。
  • 异常恢复：再次产生原因时复用同一提示组件并更新文字；成功进入主界面后清除旧提示，避免跨页面残留。该操作不发起网络或登录重试。
  • 测试用例：T10、T11、T13、T16。

OP05 成功页面显示

  • 前置条件：当前有效尝试已经完成模拟账号的查询／创建及必要持久化。
  • 操作处理：隐藏 L00、D00、F00，显示 M00；不增加成功弹窗、奖励窗口、返回或注销按钮。
  • 成功结果：显示“占位主界面”“模拟登录成功”及本次实际服务器名称；下层登录控件不再接收输入。
  • 失败反馈：本页为同步本地显示，不新增业务失败分支；未成功的登录仍留在登录窗口并遵循 OP03。
  • 异常恢复：进程重启回到登录窗口，复用已保存的安装 ID、选服及同服账号；不自动登录。
  • 测试用例：T09、T14、T15、T16。
