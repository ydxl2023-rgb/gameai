1 设计目标

以本地安装标识串联选服、模拟登录、首次建号与成功占位状态，形成可观察、可重复检查的移动端测试闭环。

  • 本期不连接真实登录服务；安装 ID 为本地生成并保存的标识，不是永久硬件 ID 或安全认证凭据。
  • 不引入手机号、账号密码输入、注册页面、真实认证、找回账号、跨设备继承或奖励系统。
  • 使用 1920×1080 横屏设计画布，仅支持移动触屏交互，运行时适配设备实际安全区。
  • 本轮仅交付需求。后续 UI 制作边界固定为 UILogin 登录窗口与 UIReasonToast 原因提示窗口，各包含白模、Art、装配三个阶段；本轮不拆程序或 QA 任务。
  • 业务语义与验收用例保留为制作及检查依据，不表示已经授权业务实现或执行测试。

2 功能综述

编号主题确定规则
R01安装标识首次安装使用时生成并持久化安装 ID，重复启动读取同一 ID。标识数据丢失后生成新 ID 并视为新账号，不关联或继承旧账号。
R02模拟账号以安装 ID 与 ServerId 的组合定位模拟账号。首次在对应服务器成功登录时自动建号，后续复用；不同服务器数据独立。
R03选服顺序按本地配置行顺序展示服务器。上次选择存在且可用时恢复，否则选择首个可用服；不可用服保留展示但禁选。
R04无可用服显示“暂无可用服务器”，禁用登录。空列表同时禁用选服；非空但全部不可用时可展开查看，全部条目禁选。
R05版本左上角展示测试 ICON 与完整 32 位字母数字版本号。版本仅展示，不参与登录校验、匹配或阻断。
R06处理中与成功登录中禁用选服和登录，收起下拉列表；当前有效尝试成功并完成必要保存后，进入 UILogin 内的成功占位状态，不增加第三个独立窗口。
R07失败与超时以 UIReasonToast 原因提示条反馈：屏幕中间出现，向上飘动后消失，无按钮、不拦截输入。恢复符合当前条件的操作，不自动重试。
R08表现简洁测试风格、静态背景；无开关或成功切换动画，无按钮音效。原因提示的上飘及消失是唯一必需动态反馈。

所有结果来自本地模拟，不存在真实远端提交结果未知的场景。模拟超时结束当前尝试，迟到结果不得改变页面、账号、选服或新尝试状态。玩家可手动再次登录，不增加重试按钮、网络异常窗口或真实网络状态查询。

模拟建号与成功结果属于同一有效尝试的完成步骤；失败及已超时尝试不提交新账号。同一安装 ID 与服务器组合重复成功不得重复建号。配置、标识或模拟数据读取、保存失败时不得伪装成功。

W01-WHITEBOX

depends_on=[]

3.5 操作交付标准与业务说明

以下保留完整业务语义，供 UI 状态与测试判定使用；本轮不据此拆出程序或 QA 任务。所有完整测试均见附录 A，尚未执行。

OP01 启动与本地状态恢复

  • 前置条件：应用启动，本地配置及数据可能为首次、已有或丢失状态。
  • 操作与处理中：显示 LoginBackground，读取配置、安装 ID 与上次选服；初始化未完成时禁用登录。
  • 成功反馈：缺少 ID 时生成并保存，已有则复用；恢复有效上次服或首个可用服，显示 ICON 与完整版本。
  • 失败反馈：配置或本地存储异常显示 UIReasonToast；缺有效安装 ID、配置或可用服时不登录，不能把未保存数据表示为已保存。
  • 异常恢复：重新启动重新读取，不自动发起登录；标识丢失视为新账号，不找回旧身份。
  • 测试用例：T01～T05、T12、T13、T17。

OP02 展开、浏览、选服与关闭下拉区域

  • 前置条件：初始化完成、当前不在登录中，至少有一条合法配置。
  • 操作与处理中：点击 ServerDropdown 显示 ServerSelectionPanel，按配置顺序从顶部展示；纵向触屏拖动 ServerList 只浏览，非溢出停止滚动；普通绑定刷新保留位置。
  • 成功反馈：点击可用 ServerItem 实例更新 SelectedServer、记录选择并收起 ServerSelectionPanel；点击 OutsideClickArea 外部区域仅收起且不穿透；面板空白不触发外部关闭。
  • 失败反馈：不可用项不改变选择、不追加弹窗；保存选择失败以 UIReasonToast 提示，当前内存选择可继续使用，不宣称已保存。
  • 异常恢复：以上均为本地交互，无网络处理；下次启动以实际保存结果重新校验。登录中点击 ServerDropdown 不展开。
  • 测试用例：T03～T07、T13。

OP03 模拟登录与首次建号

  • 前置条件：安装 ID 有效且已保存，选服可用，无正在处理的尝试。
  • 操作与处理中：点击 LoginButton 固定本次安装 ID 和 ServerId，发起一次本地模拟；收起 ServerSelectionPanel，禁用 ServerDropdown、LoginButton，LoginStatus 显示“登录中…”，不调用真实登录 API。
  • 成功反馈：当前有效尝试成功时查找或创建对应模拟账号，必要保存完成后进入 LoginSuccessPanel；同服复用、跨服隔离。
  • 失败反馈：模拟失败或提交本地数据失败不进入 LoginSuccessPanel；UIReasonToast 显示原因，按当前资格恢复 ServerDropdown、LoginButton 及“登录”文案。
  • 异常恢复：模拟超时结束当前尝试，提示“模拟登录超时，请再次登录”，恢复操作且不自动重试。旧回调不得建号、跳转、解除新尝试锁定或覆盖选择；进程重启回到登录。
  • 测试用例：T08～T11、T13～T16。

OP04 原因提示的显示与自动隐藏

  • 前置条件：启动、保存或模拟登录产生需告知的失败或超时原因。
  • 操作与处理中：ReasonBackground 与 ReasonText 从屏幕中间显示并播放 AN01，上飘及消隐；不接收射线，没有确认、关闭、重试按钮。
  • 成功反馈：AN01 结束后隐藏 UIReasonToast；底层操作资格由真实状态决定，模拟失败和超时不等待提示结束即可恢复操作。
  • 失败反馈：显示准确中文类别，不把超时显示成成功，不编造远端认证错误；提示播放不是登录业务请求。
  • 异常恢复：连续反馈复用同一实例，以最新原因重播；进入成功占位时清理提示，迟到反馈不覆盖成功状态；不触发网络查询或登录重试。
  • 测试用例：T10、T11、T13、T16、T17。

OP05 成功占位状态显示

  • 前置条件：当前有效尝试已完成账号查找或创建及必要持久化。
  • 操作与处理中：保留 UILogin，隐藏其 LoginBackground、ServerSelectionPanel 及 UIReasonToast，显示 LoginSuccessPanel。
  • 成功反馈：显示“占位主界面”“模拟登录成功”和实际服务器名；下层登录控件不再接收输入，不新增成功弹窗、奖励、返回或注销按钮。
  • 失败反馈：同步本地显示不新增业务失败分支；未成功登录留在 LoginBackground 并按 OP03 处理。
  • 异常恢复：重启回到登录，复用已保存安装 ID、选服及账号，不自动登录；本页没有本地返回操作。
  • 测试用例：T09、T14～T17。

预期结果：显示“暂无可用服务器”，登录禁用；零行不能展开，全不可用可查看不可选，不产生登录尝试。

T06 列表容量、裁剪与触屏手势

前置条件：分别有 1、4、6 项配置。

操作步骤：展开，纵向拖动至首尾，从不可用项起拖；滚动后触发普通显示刷新，再关闭重开。

预期结果：1、4 项不滚动；6 项显示四个完整项与下一项局部并可到末项；边界钳制，视口外不显示、不命中；拖动不选服、不登录。普通刷新保留位置，重新展开从顶部开始。

T07 下拉关闭及点击隔离

前置条件：下拉已展开。

操作步骤：点击面板空白，再点击列表外部；用单项配置点击未被列表覆盖的原登录区域。

预期结果：空白吸收点击；外部点击只关闭下拉，不改变选择或穿透登录；无开关动画。

T08 登录中防重复

前置条件：标识、选服有效，模拟处理保持未完成。

操作步骤：点击登录，再连续点击登录及选服。

预期结果：只有一个有效尝试；“登录中…”显示，两个按钮禁用，下拉收起，目标服务器不变，无真实登录 API。

T09 成功建号与窗口内占位状态

前置条件：当前安装 ID 在选定服无账号，夹具返回成功。

操作步骤：点击登录并等待完成。

预期结果：建号与保存完成后，UILogin 保留根 UILogin，隐藏 LoginBackground、ServerSelectionPanel、UIReasonToast，显示 LoginSuccessPanel 和实际服务器；不产生第三个独立窗口、成功弹窗或奖励页面。

T10 明确失败与手动再次登录

前置条件：夹具返回模拟失败。

操作步骤：登录，观察 UIReasonToast；提示未结束时选服或再次登录。

预期结果：不进入成功状态、不提交新账号；原因条从中部出现，上飘消失，无按钮、不阻塞；恢复操作，只有再次点击才发起新尝试。

T11 超时与迟到结果

前置条件：旧尝试超时，保留其成功回调。

操作步骤：等待超时，改选服并开启新尝试，再释放旧回调。

预期结果：提示“模拟登录超时，请再次登录”，不自动重试；旧回调不建号、不跳转、不解除新锁定、不覆盖选择。

T12 版本完整展示与业务独立

前置条件：正常 32 位版本、异常版本文本、缺失展示信息三种测试输入。

操作步骤：分别启动观察并完成模拟登录。

预期结果：正常字符串完整无省略；异常字符串不触发认证或阻断；缺失时显示“版本信息缺失”，模拟结果和选服仍独立。

T13 配置及本地存储异常

前置条件：分别注入重复 ServerId、无效布尔值、非法名称、标识保存失败、选服保存失败、账号保存失败。

操作步骤：触发对应启动、选服或登录操作。

预期结果：配置整体无效或标识不可用时不登录；选服保存失败不宣称记忆成功，内存选择可用；账号保存失败不进入成功状态；准确提示原因，不伪造认证结果。

T14 同服复用与跨服隔离

前置条件：一个安装 ID、两个可用服。

操作步骤：两次重启分别成功登录服一，再登录服二；修改服一名称后重启；移除后恢复同一 ServerId。

预期结果：服一只建号一次，服二数据独立；改名不改变身份，移除不清数据，恢复同 ID 使用原数据，改 ServerId 则视为不同域。

T15 进程中断及重启

前置条件：分别处于处理中及成功占位。

操作步骤：终止进程并重新启动。

预期结果：回到 UILogin 登录状态，不恢复旧请求、不自动登录，复用已保存 ID 与有效选服；已成功保存的账号不重复创建。

T16 提示复用及状态清理

前置条件：可连续触发不同原因，随后可模拟成功。

操作步骤：连续触发 UIReasonToast，再手动登录成功。

预期结果：仅一个提示实例，更新最新原因并重播 AN01，不堆叠；成功清理旧提示，迟到反馈不覆盖成功状态，无登录触控残留。

T17 安全区、名称与表现范围

前置条件：不同安全区横屏设备、最长允许服务器名。

操作步骤：逐一查看普通、展开、处理中、提示、成功占位状态并完成触屏流程。

预期结果：关键内容避开刘海与手势区，版本完整、名称可读、ICON 不变形；静态背景，无开关动画、按钮音效或额外特效，仅 AN01 上飘消隐且不拦截输入。
