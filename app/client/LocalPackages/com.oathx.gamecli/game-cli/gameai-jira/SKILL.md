# JIRA 访问

- 从配置获取站点、项目、字段映射和工作流；文档字段名称不等同于真实字段 ID。
- 写入前读取当前任务、版本、依赖和审批，仅修改本次任务负责的字段。
- 创建、更新和迁移遵守当前任务授权；本技能本身不授权任意外部写入。
- JIRA 保存状态、审批、重试、执行 ID、幂等键和结果引用；大文件存于 Git 或对象存储，回写 URL/Hash。
- 操作前检查执行记录；结果未知或崩溃恢复时核对目标系统已有产物，避免重复创建。
- 先查后写不是并发锁；并发写入使用实际支持的版本检查或串行执行，不能宣称严格 exactly-once。
- 状态通过实际工作流迁移，审批关联批准人及输入/产物版本。
- JIRA 不可用、权限不足或配置缺失时返回 blocked，不用本地 JSON/数据库替代。

返回真实 issue key、字段变更、迁移结果、执行记录引用和错误。超时且结果未知时标记待核对，不直接重复创建。
