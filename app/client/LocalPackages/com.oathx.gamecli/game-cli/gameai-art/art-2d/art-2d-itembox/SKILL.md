# 二维道具框生产

执行前读取 [二维美术](../SKILL.md) 和 [Art 主技能](../../SKILL.md)。本技能只规定道具框生产，任务状态、派发和审核由平台管理。

## 交付目录（硬性规范）

- 以目标工程根为基准，统一保存到 `deliveries/<任务编号>/`；目录名称必须使用平台真实任务编号，如 `deliveries/A-0000269/`。禁止用需求名、角色名或临时模型编号代替任务编号。
- 不存在则自动创建。目录和清单使用工程相对路径，不写死盘符。没有真实任务编号时仅做预演，不伪造正式交付。
- 本任务的源图、分层图、效果图、提示词、清单和检查证据全部存放在此目录内；可用 `source/`、`layers/`、`preview/` 组织文件，不把同一任务产物分散到其他目录。
- 重做任务时创建 `v002/` 等版本子目录，保留旧成果；不得覆盖其他任务或未确认替换的文件。

## 分层与尺寸（硬性规范）

- 最终道具框、每张独立分层 PNG 和单个合成效果 PNG 均为 **128×128 像素**、RGBA、相同画布、相同原点；禁止交付高分辨率源图并仅在清单中标注128。
- 四层固定为：`L1-background.png` 背景层、`L2-icon.png` 图标层、`L3-text.png` 文本层、`L4-frame.png` 框体层。
- L1 只包含框内底图／底色；L2 只包含道具图标；L3 只包含名称、数量等文字；L4 只包含边框／描边，内部必须透明。
- 画布外部及各层未占用区域为真实透明像素，不能用白底或棋盘格图案冒充透明。不能从合成图硬切分出四层并声称原生分层。
- 顺序固定为 L1 → L2 → L3 → L4；四层必须能在相同画布直接叠加还原最终效果，框体不遮挡文字和图标。分层文件保留四个稳定标识。
- 通用默认安全区：框体在画布内侧，图标位于框内上部／中央，数量靠框内右下角；细节以需求批准线框或用户新指令为准，不改变玩法规则。
- 多个奖励逐项复用道具框，R01活动档位、R02成功奖励、R03补发记录共享组件；档位状态、领取按钮属于上层界面，不合入道具框资产。

## 生成与输出

- 先确认道具用途、风格、参考、名称／数量示例和当前任务授权。用户明确要求生图时调用实际可用的生图工具制作位图资源，不能用程序绘制占位图替代生产图。
- 背景、图标和边框分别生成；提示词明确其层职责、空白区、构图位置和透明要求。保持同一材质、配色、视角和笔触。记录每层实际提示词、生成工具、可取得的模型信息；未知模型和随机种子为 null。
- 文本优先使用可复用字体／文本组件，交付对应源定义及透明 PNG 示例；避免依赖生图模型生成不可复用或错误的数字。示例文字不定义游戏奖励数值，实际值由运行时配置提供。
- 保留生图原始尺寸与 alpha 文件于 `source/`。按最终尺寸进行工程导出；缩放、数量文字排版和四层合成属于确定性的交付处理，必须记录使用工具与参数，不重绘生图主体或以处理步骤冒充模型生成。
- 最后按四层确定顺序合成为 `preview/itembox-128.png`。此图是单个128×128独立效果图，不是包含标题、注释或多格图集的展示板。检查四层重新合成和效果图一致。
- 另提供分层对照预览／独立HTML说明，显示层名称和顺序；展示板可以放大，但不能替代128×128正式资产。

## 交付检查

- 检查所有正式 PNG 的实际宽高、格式、透明通道、可见像素和统一对齐；L4中心透明，四层均非空，L3数量清晰且不截断。
- 检查最终效果图的透明外部、边缘、图标识别和128像素下文字可读性；没有白边、背景泄漏、误合层和框体遮挡。
- 写入 `manifest.json`：真实任务编号、需求版本、用户追加规格、源图／各层／效果图相对路径、SHA-256、尺寸、叠放顺序、文本示例、导入设置、检查证据和制作方式。
- Unity建议导入：Sprite(2D and UI)、Single、sRGB、Alpha Is Transparency；Max Size至少128，关闭MipMap，UI压缩按实际清晰度验证。`.meta`交给Unity正常生成，不伪造GUID。
- 只在实际生成、文件与尺寸检查通过后报告资源制作完成；视觉人工抽检、平台回写、任务状态更新须分别说明是否完成。不能伪造固定Art Agent执行或自行放行下游。

## 工程导出工具

Windows 下可使用 `pwsh.exe -File scripts/export-itembox.ps1 -DeliveryDirectory <任务目录> -Quantity 99`。先将三个生图源文件放到该目录的 `source/L1-background-generated.png`、`source/L2-icon-generated.png`、`source/L4-frame-generated.png`。工具仅做128尺寸导出、独立文字排版与按序合成，不替代生图，不覆盖现有文件。字体示例为Arial，正式中文名称需明确中文字体和排版区域。
