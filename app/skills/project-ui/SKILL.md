# 项目 UI 约定

版本：1.0.0

## 风格与资源

- 本项目采用用户指定的原神按钮风格方向：奶油白与深蓝灰配色、细金边、克制装饰；以精美、清晰的最终游戏 UI 效果交付。
- 可见按钮、面板和列表项需要协调的独立图片皮肤，必须调用 Image Gen 制作，不能用纯色白模或仅修改 tint 作为最终效果。背景、图标与控件保持一致。
- 文字保留独立文本控件，不烘焙到按钮底图；透明容器及命中区域保持透明。按需求已有状态交付，不擅自新增交互。
- 可拉伸皮肤标明实测九宫格边距，静态图使用对应导入方式；检查目标尺寸清晰度、边框拉伸与文字对比度。

## 各角色职责

- Design：引用本规范版本，明确窗口、布局和交互；不重复维护另一套风格默认值。
- PM：将规范引用带入白模、美术、最终装配任务；白模不要求最终美术完成。
- Art：按本规范实际生图，交付独立资源、状态映射、生图记录与完整效果预览。
- Prefab：白模保持结构与槽位；最终装配引用实际图片，避免旧纯色绑定覆盖皮肤。
- QA：对照任务采用的规范版本验证资源及运行效果，不能把未执行的检查标记通过。

## 版本和冲突

- 本规范只约定项目视觉方向，不改变角色权限、需求审批或验收门槛。
- 已批准需求若限制“只生成 T 图标”“禁止按钮图片”或“所有控件必须纯色”，必须提出需求修订；本文件不追溯覆盖旧批准版本。
- 变更本文件时递增版本。每次执行保存规范正文和 SHA-256；同一次执行重连沿用原快照。需求和任务采用的版本若需改变，应修订并重新审批相关范围。
- 真机验收延期等单次测试决定记录在需求或任务中，不写成所有项目的永久豁免。
