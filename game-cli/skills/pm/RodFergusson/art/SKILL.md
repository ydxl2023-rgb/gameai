# PMArt

## 单一职责

仅补全每个独立窗口的一项美术资源包任务，不按资源数量拆单。依据批准线框和 UI 白模契约的尺寸、控件属性、资源槽位进行规划；白模未交付时标明前置依赖，不假称已读取。可复用资源只在归属窗口资源包中生产一次，其他实例引用，不另建资源任务；不把整个多窗口文档复制成相同任务说明。区分静态图与九宫格、透明区域、图层、切片、动画与音效需求。奖励道具框按背景、图标、文本、框体分层，图像资源要求生图构造完整效果并交付独立资源及组合预览。交付统一位于任务编号目录。不得生成资源、装配 Prefab 或拆程序任务。

## 输入与输出契约

读取宿主指定的批准版本、全局规则、负责章节完整 HTML、共享组件及跨专业契约，核对宿主提供的版本与哈希校验结果，不重复调用工具做宿主已完成的哈希校验。不得仅凭摘要或线框截图拆任务。缺少明确结论时报告缺口，不自行扩大需求或重新批准。

每项草案包含稳定临时编号、来源章节/锚点、所属独立窗口、范围、不含范围、交付文件、前置依赖与交付验收标准。验收覆盖前置条件、操作处理、成功结果、失败提示、异常恢复和测试用例。需要阅读的任务单据使用独立 HTML，完整保留相关原文、样式、线框和控件层级，不用摘要代替。

跨专业依赖使用来源锚点和交付契约标识，由总 PM 合并解析为真实任务编号；不能猜测平台编号。按宿主 schema 返回草案与缺口；无 schema 时采用公共结果结构。由 RodFergusson 在同一次执行中汇总，不直接发布、审批、启动制作或改变权限。

遵守 [公共契约](../../../common/SKILL.md)、[单据规范](../../../common/gameai-task-writing/SKILL.md)、[交付规范](../../../common/gameai-task-delivery/SKILL.md)、[HTML 规范](../../../common/gameai-document-format/SKILL.md)。只使用自己的成员技能目录，这是 RodFergusson 的内部规划模块，不是独立 Agent，不调度其他 PM。

本模块仅定义 PM 拆分规则，不执行制作。当前 UI 调试按独立窗口交付，不额外拆列表项或单个控件；美术按窗口资源包交付。

## 资源清单边界

严格按 ui-production-contract 的 resourceSlots.slotId、bindings、generationPolicy、kind 和 deliverySize 核对生产范围。同一窗口打包一项 Art 任务，资源映射指向真实控件；同一窗口复用资源共享槽位；当前 schema 未支持的跨窗口生产关系须报告，不伪造依赖。容器和文字不当作图片生成。资源表、线框、控件属性或白模契约不一致时报告缺口，不猜尺寸或九宫格模式。

服务端固定骨架优先：本模块仅用于补充内容，不再决定任务数量、编号、角色或依赖。严格按 RodFergusson 主技能“固定骨架补全”执行；发现矛盾返回阻塞，不自行修订已批准清单。

粒度统一遵守 [UI 公共交付契约](../../../common/gameai-ui-delivery-contract/SKILL.md)，只读预演遵守 [主技能](../SKILL.md)。同一窗口的图片、图标、状态样式及已约定表现合并为资源包内交付清单；零新增图片仍交付复用核对与资源映射，不删除 Art 阶段，也不虚构图片生产。

## 完整视觉资产归属
窗口 Art 任务必须覆盖冻结契约 resourceSlots、animations、effects 所需的图片、字体、动画片段和控制器。不可只分配图片而把动画制作遗漏给最终装配；最终装配负责绑定和动态验证，不承担未分配的上游资产制作。仍保持每窗口三阶段，不新增细碎动画任务。
