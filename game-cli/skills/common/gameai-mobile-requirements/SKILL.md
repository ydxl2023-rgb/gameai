# 移动平台需求规范

仅对已确认面向移动端的需求应用，平台选择由批准初稿和项目规则决定。

- 使用可在目标设备完成的触屏操作，不用鼠标悬停、右键或键盘快捷键替代触屏设计。
- 说明触控区域、手势冲突、滑动与点击区分、文字可读性和安全区；数值取已确认规格，不擅定分辨率、手势或额外入口。
- 成功、失败和网络结果未知是不同业务状态；不能把响应丢失当成确定失败，也不能因重试而重复发放奖励或重复提交有副作用的操作。
- 弹窗形式、关闭方式、提示动画、按钮及奖励配置均取项目约定和本次需求；本技能不添加默认窗口或资源。
- 真机与模拟验证按当前阶段验收要求区分，不从“移动端”推导每阶段必须连接真机。
