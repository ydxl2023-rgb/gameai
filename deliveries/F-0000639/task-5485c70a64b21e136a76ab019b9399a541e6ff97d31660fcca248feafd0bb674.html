3.2 服务器下拉展开

由 B01 进入，覆盖在登录窗口之上。选择可用服务器后返回收起状态；点击列表外区域仅关闭下拉层。

低保真图。图中六条示例服务器需要纵向滚动，一屏显示四条完整记录及第五条的局部背景；虚线为裁剪边界，箭头为辅助说明。登录按钮被下拉层覆盖时不得接收点击。

3.2.1 本窗口结构分解

D00 下拉根容器（透明 Panel；位于 L00 上方）
└─ S0 D01 下拉捕获背景（Background / Image，透明）
   └─ S0 D02 下拉面板背景（Image）
      └─ S0 D03 服务器滚动列表（ScrollRect）
         └─ S0 D04 服务器裁剪区域（Viewport + RectMask2D + 透明 Image）
            └─ S0 D05 服务器内容（Content / Panel）
               └─ Sn D07[n] 服务器选择按钮（Button；UI-BUTTON 列表项变体）
                  ├─ S0 D08[n] 条目背景（Image）
                  └─ S1 D09[n] 服务器名称与状态（TMP_Text）
从底到顶：L00 → D00；D01 接收列表外点击，D04 与条目接收列表内触控。

3.2.2 控件属性与复用标注

编号／父节点／顺序局部布局与类型交付约束
D00／屏幕／L00 上方透明 Panel，四边拉伸与登录窗口同画布；根节点不接收射线。
D01／D00／S0Background / Image，(0,0,1920,1080)Simple 透明纯色，raycastTarget=true；仅未被列表命中的点击关闭下拉层，本次点击不得穿透。
D02／D01／S0Image，(610,526,700,H)Simple 静态纯色，raycastTarget=true；面板空白处吸收点击，不选服、不关闭。H=min(24+80N,360)，N 为条目数。
D03／D02／S0ScrollRect，(12,12,676,H−24)horizontal=false，vertical=true；无滚动条；Viewport=D04，Content=D05；采用边界钳制，不越界停留。
D04／D03／S0Viewport + RectMask2D + Image；铺满 D03Simple 透明纯色，raycastTarget=true，用于捕获空白区拖动；裁剪全部内容与点击范围。
D05／D04／S0Content / Panel；(0,0,676,80N)，顶部锚定垂直排列，间距 0，按配置行顺序；无图片，不拦截输入。
D07[n]／D05／SnButton；(0,80n,676,80)，n 从 0 开始服务器选择按钮，复用 UI-BUTTON；可用项可点，不可用项禁选但允许起始拖动；单击选择与拖动互斥。
D08[n]／D07[n]／S0Image；铺满 676×80Simple 纯色；选中、普通、不可用三种样式；raycastTarget=true，点击事件归属 D07[n]，拖动交 D03。
D09[n]／D07[n]／S1TMP_Text；(24,8,628,64)名称加“已选择”或“不可用”；最多两行，完整显示配置允许长度；raycastTarget=false。

N 为本地配置实际条目数，不新增业务数量上限。一至四项时面板随内容缩短且不滚动；五项及以上使用 336 高度视口，显示四项与下一项局部。Content 未溢出时停止滚动。没有嵌套滚动列表，同一次拖动只由 D03 处理，不能误触条目或下层登录按钮。

每次展开从列表顶部展示，不因打开下拉框改变已选服务器；选择结果以名称及状态文字保持可见。点击不可用项不改变选择，不追加业务弹窗。
