3.6 复用组件与统一属性

模板实例及定义依赖与范围
UI-BUTTON 文本按钮容器 Button → S0 静态底色 Image → S1 TMP_Text；业务名称由实例绑定。B01 额外包含 S2 箭头文字。B01、B02、D07[n] 使用不同样式。先交付基础按钮结构，再组装选服控件和列表项，最后组装登录窗口。按钮模板不自带登录行为。
UI-SERVER-ROW 服务器条目D07[n]／D08[n]／D09[n]；676×80；名称、可用性、选中状态来自当前数据。复用 UI-BUTTON 列表项变体；同类条目只生产一份模板。D03、D04、D05 随列表组装交付。
UI-TOAST 原因提示F00／F01／F02，组件图及属性见 3.4；各失败原因复用同一结构。纯色底板、原因文字与 AN01 表现组成同一交付结果；不增加可操作按钮。
窗口基础布局L00→L01、M00→M01；透明根 Panel 与静态背景。透明 Panel、Content、Viewport 是结构节点，不对应独立贴图或机械拆分的资源任务。
UI-BUTTON 分层示意（实例尺寸见各窗口属性表）
按钮容器：Button / RectTransform
  S0 ┌────────────────────┐ 静态 Simple 背景，提供命中范围
  S1 │    业务状态文字    │ TMP_Text，不接收射线
     └────────────────────┘
B01 追加 S2 箭头文字；不是单独图片。
从底到顶始终为背景 → 文字 → 实例附加文字。

所有 Simple 纯色底板可随容器拉伸，无图案边缘保护要求；ICON 保持比例，不拉伸变形。没有 Sliced 图片，因此本期不设置 Sprite.border。文本保持独立节点，不烘焙进 ICON 或底板。

普通按钮使用默认、按下、禁用的静态色差提供触屏反馈，不制作过渡动画或音效。全部实际触控区域位于安全区，文本与装饰图片不夺取按钮和滚动列表的输入。
