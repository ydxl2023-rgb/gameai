3.1 登录窗口

3.1.1 界面线框布局

应用启动进入此窗口。主区域只有服务器下拉框和登录按钮；左上角提供测试 ICON 与版本号。登录窗口没有额外注册、找回、设置或退出按钮。

低保真图。入口为应用启动；点击 B01 展开选服，点击 B02 发起模拟登录。版本号为 32 位示例字符串，不显示省略号。

3.1.2 本窗口结构分解

L00 登录根容器（透明 Panel）
└─ S0 L01 登录背景（Background / Image）
   ├─ S0 L02 测试 ICON（Image）
   ├─ S1 L03 版本号（TMP_Text）
   ├─ S2 B01 服务器下拉框（Button，UI-BUTTON 选服变体）
   │  ├─ S0 B01-BG 下拉框底色（Image）
   │  ├─ S1 B01-T 当前服务器文字（TMP_Text）
   │  └─ S2 B01-A 展开箭头“▾”（TMP_Text）
   └─ S3 B02 登录按钮（Button，UI-BUTTON 主按钮变体）
      ├─ S0 B02-BG 登录底色（Image）
      └─ S1 B02-T 登录状态文字（TMP_Text）

3.1.3 控件属性与复用标注

编号／父节点／顺序类型与局部布局内容、输入与图片模式
L00／屏幕／窗口基础层透明 Panel；四边拉伸，1920×1080不添加透明 Image；不接收输入。
L01／L00／S0Background / Image；(0,0,1920,1080)，拉伸静态纯色 #EEF0F3；Simple，纯色允许铺满，不要求贴图；raycastTarget=false。
L02／L01／S0Image；(150,90,88,88)，左上锚点测试 ICON；Simple，保持 1:1，不裁剪图标；raycastTarget=false。
L03／L01／S1TMP_Text；(258,102,1400,64)，左上锚点绑定展示版本字符串；34 设计字号，单行完整显示，适配时等比缩放，不截断、不省略；raycastTarget=false。
B01／L01／S2Button；(610,430,700,96)，居中布局；复用 UI-BUTTON点击展开服务器列表。命中整个矩形；登录中禁用。显示已选名称或“暂无可用服务器”。
B01-BG／B01／S0Image；(0,0,700,96)，铺满按钮Simple 纯色静态背景，禁用时降低对比度；raycastTarget=true，事件归属 B01。
B01-T／B01／S1TMP_Text；(32,16,570,64)名称来自配置；过长可在此处省略，完整名称在列表项显示；raycastTarget=false。
B01-A／B01／S2TMP_Text；(620,16,48,64)文字箭头“▾”，非图片资源；raycastTarget=false。
B02／L01／S3Button；(760,580,400,104)，居中布局；复用 UI-BUTTON业务名称始终为“登录按钮”；状态文案为“登录”或“登录中…”；无可用服及处理中禁用。
B02-BG／B02／S0Image；(0,0,400,104)Simple 纯色静态底色；raycastTarget=true，命中事件归属 B02。
B02-T／B02／S1TMP_Text；(24,20,352,64)状态文字居中、不省略；raycastTarget=false。
